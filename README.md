# 벗나루 청춘태권도 홈페이지

## 관리자 CMS

- 서버 실행: `npm install` 후 `npm start`
- 관리자 주소: `/admin.html`
- 최초 아이디: `백승봉`
- 최초 비밀번호: `1234`
- 최초 로그인 직후 6자 이상의 새 비밀번호로 반드시 변경해야 합니다.
- 관리자 화면에서 기본정보·운영기관·소식·사진 목록을 수정하고 사진 파일을 업로드할 수 있습니다.
- 운영 환경에서는 `SESSION_SECRET` 환경변수를 길고 무작위인 값으로 설정하세요.

## 폴더 구조

```
index.html      메인
about.html      벗나루 소개
program.html    청춘태권도 (수업 내용)
activity.html   활동 현황 (운영 기관 · 연혁 · 사진)
news.html       소식
contact.html    문의하기
assets/style.css   전체 디자인
assets/site.js     데이터 + 공통 헤더/푸터
photos/            사진 폴더
```

## 고칠 곳은 assets/site.js 한 파일

- `[1] SITE` — 대표번호, 이메일, 주소, 운영시간. 모든 페이지의 헤더·문의·푸터에 반영됩니다.
- `[2] SITES` — 운영 기관 목록. 한 줄 추가하면 메인·활동현황 표와 연혁이 같이 갱신됩니다.
- `[3] PHOTOS` — 활동 사진과 설명.
- `[4] NEWS` — 소식. 비워두면 "등록된 소식이 아직 없습니다"가 표시됩니다.

## 사진

`photos` 폴더에 아래 이름으로 넣습니다.

| 파일 | 쓰이는 곳 | 권장 |
|---|---|---|
| hero.jpg | 메인 첫 화면 | 가로 2000px 이상, 인물이 오른쪽 |
| p1.jpg ~ p6.jpg | 활동 현장 | 가로 1200px 이상 |
| about.jpg | 소개 페이지 | 세로로 긴 편이 좋음 |
| program.jpg | 수업 내용 페이지 | 세로로 긴 편이 좋음 |

사진이 없으면 자리에 파일명이 표시됩니다. 넣으면 자동으로 사라집니다.
어르신 얼굴이 나오는 사진은 게시 동의를 받아두세요.

## 남은 작업

1. `SITE.tel`, `SITE.email`, `SITE.address` 실제 값으로 교체
2. 사진 넣기
3. `program.html`과 `about.html`의 "※" 표시 문단을 실제 내용으로 교체
4. 문의 폼을 Formspree 또는 구글 폼으로 교체 (지금은 mailto 방식이라 담당자 PC에 메일 프로그램이 없으면 실패)
